# Local website fonts

The current site uses Latin subsets of **Anton** for display headings and **DM Sans** for body text. Both are free, open-source fonts distributed under the SIL Open Font License 1.1. Full licenses are included alongside the font files.

- Anton: https://github.com/google/fonts/tree/main/ofl/anton — `anton-OFL.txt`.
- DM Sans: https://github.com/google/fonts/tree/main/ofl/dmsans — `dm-sans-OFL.txt`.

The DM Sans subset retains variable weights and uses optical size 14. No external font service or runtime font download is required. The earlier personal-site font, Bricolage Grotesque, is also retained with its license; the current brand page does not load it.
