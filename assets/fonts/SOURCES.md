# Local website fonts

The site bundles Latin subsets of two free, open-source font families from the official Google Fonts repository. Both are licensed under the SIL Open Font License 1.1. Their full license texts are included alongside the fonts.

- **Bricolage Grotesque**: https://github.com/google/fonts/tree/main/ofl/bricolagegrotesque — `bricolage-OFL.txt`.
- **DM Sans**: https://github.com/google/fonts/tree/main/ofl/dmsans — `dm-sans-OFL.txt`.

WOFF files retain their variable weight axes. The display font uses optical size 96 and standard width; the body font uses optical size 14. No external font service or runtime download is required.
